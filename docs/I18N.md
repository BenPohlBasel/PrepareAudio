# PrepareAudio in vier Sprachen

Deutsch, Englisch, Französisch, Italienisch — dieselben vier wie LocalTranscript.
Beim ersten Start gilt die Systemsprache (sonst Englisch); umgeschaltet wird im
Info-Feld, die Wahl bleibt gespeichert.

## Mechanik

- `ui/i18n.js` ist der Kern: `I18N.add`, `t(key, params)`, `tn(key, n)`,
  `I18N.apply()`, `I18N.onChange(fn)`, `I18N.locale()`. Siehe Kopfkommentar.
- Die Wörterbücher liegen in `ui/i18n/`, eine Datei je Bereich. Jede Datei ist
  `I18N.add({ "key": { de, en, fr, it }, … })`. Alle vier Sprachen sind Pflicht.
- Schlüssel-Präfixe: `common.` (Kopf, Reiter, gemeinsame Formate, Meldungen, die
  mehrere Reiter nutzen), `page.` (statischer Text aus `index.html`, liegt in
  `common.js`), `merge.`, `sync.`, `master.`, `info.`.
- In JavaScript nie die globale Funktion `t` direkt aufrufen, wo `t` auch eine
  lokale Variable sein kann (Zeiten in der Timeline!). Stattdessen je Datei
  `const tr = (k, p) => I18N.t(k, p); const trn = (k, n, p) => I18N.tn(k, n, p);`.
- Statisches HTML trägt `data-i18n…`-Attribute. Elemente, deren Text JavaScript
  setzt, bekommen **kein** `data-i18n` (sonst überschreibt `apply()` sie).
- Beim Sprachwechsel ruft jeder Bereich über `I18N.onChange` sein `render()`
  auf; die Timeline zeichnet neu.
- Zahlen: `toLocaleString(I18N.locale(), …)` statt fest `'de-DE'`.
- Das Rust-Backend übersetzt seine eigenen Meldungen (Fehler, Hinweise,
  Fortschritt, Formatangaben) selbst. `set_language(lang)` setzt die Sprache;
  `i18n.js` ruft es beim Start und bei jedem Wechsel. Texte, die schon in einem
  Ergebnis stehen (Hinweise eines Scans), wechseln erst beim nächsten Scan.

## Stil

- Deutsch: du. Englisch: britische Schreibung (synchronise, licence), sachlich.
  Französisch: vous. Italienisch: tu. Kurz, wie in einer Mac-App.
- Anführungszeichen: de „…“, en “…”, fr « … », it «…».
- Einheiten und Fachbegriffe bleiben: LUFS, dBTP, LU, kbit/s, kHz, EBU R128,
  WAV, RF64, MP3, Stereo/Mono (fr stéréo/mono), Playhead (fr tête de lecture,
  it testina), Timeline.
- Ordnernamen `tracks`, `sync`, `master` werden **nie** übersetzt (sie sind
  Ordnernamen auf der Platte).

## Keine Marken, klare Eingaben

Die App nennt keinen Gerätehersteller (kein «DJI», kein «Mic 2»). Sie spricht
von **Aufnahme-Teilen** (recording chunks) eines **Audiorecorders** und sagt klar, was sie annimmt:

- **Zusammenfügen:** nur **WAV**, von jedem Recorder. Teile, die ein Recorder
  bei langen Aufnahmen schreibt; erkannt an der Aufnahmezeit (Metadaten wie
  Broadcast-WAV `bext`, Dateiname oder Dateidatum) und an der Nahtstelle im
  Audio. Details: `docs/CHUNK-ERKENNUNG.md`.
- **Synchronisieren:** **WAV** (die Tracks aus Schritt 1 oder rohe Teile) sowie MP3,
  M4A/AAC, FLAC, ALAC, AIFF, CAF, OGG — einmal dekodiert und zwischengespeichert,
  erzeugt wird immer WAV.
- **Mastern:** WAV (auch RF64, 32-bit float), MP3, M4A/AAC, FLAC, ALAC, AIFF,
  CAF, OGG Vorbis.
